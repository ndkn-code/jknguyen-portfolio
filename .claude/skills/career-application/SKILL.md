# Career application bridge

The private Career OS repository is the sibling folder `../jknguyen-career`. This portfolio is not the career profile database.

Before answering the user, read these files from Career OS completely:

- `../jknguyen-career/AGENTS.md`
- `../jknguyen-career/.claude/skills/application-manager/SKILL.md`
- `../jknguyen-career/.claude/skills/resume-tailor/SKILL.md`

Then complete the Career OS link-only workflow in that repository. Use its direct HTTP importer, including its Workday CXS adapter. Preview the URL, apply a clear exact snapshot without asking permission, create/update the application records, select verified evidence, render both the resume PDF and cover-letter PDF, run validation, and present clickable paths to both files.

Never use computer use, interactive browser automation, search snippets, or job-board mirrors as substitutes for the exact posting. Never end with only a role summary, an offer to tailor later, or a permission question. If exact retrieval or a factual conflict blocks safe generation, state that single concrete blocker. Submission, sending, scheduling, Git commits, and pushes require separate explicit authorization.
